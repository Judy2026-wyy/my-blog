## 题目

给你一个链表数组，每个链表都已经按升序排列。

请你将所有链表合并到一个升序链表中，返回合并后的链表。

### 示例 1：

```
输入：lists = [[1,4,5],[1,3,4],[2,6]]
输出：[1,1,2,3,4,4,5,6]
解释：链表数组如下：
[
  1->4->5,
  1->3->4,
  2->6
]
将它们合并到一个有序链表中得到。
1->1->2->3->4->4->5->6
```

### 示例 2：

```
输入：lists = []
输出：[]
```

### 示例 3：

```
输入：lists = [[]]
输出：[]
```

## 第一轮提交代码

```python
import heapq

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def mergeKLists(self, lists: list[ListNode | None]) -> ListNode | None:
        heap = []
        # 把每个链表的头结点放入最小堆中
        for index, node in enumerate(lists):
            if node is not None: # 考虑 Lists= [[]]的情况
                heapq.heappush(heap, (node.val, index, node))
            #                          ↑ 按它排序  ↑ 平局时比较  ↑ 真正要用的节点

        # 存好最小堆后开始创建合并的升序链表
        dummy = ListNode(0)
        tail = dummy

        # 循环开始弹出每一个节点并插入最小堆
        while heap:
            val, idx, node = heapq.heappop(heap)
            tail.next = node
            tail = node  # tail 始终指向结果链表的最后一个节点

            # 3. 补位：被弹出节点的下一个节点有资格进堆
            if node.next is not None:
                heapq.heappush(heap, (node.next.val, idx, node.next))

        return dummy.next
```

## 我的解题思路

```
import heapq

heap = []                      # 空堆就是一个空 list

heapq.heappush(heap, 5)        # 插入，O(log n)
heapq.heappush(heap, 1)
heapq.heappush(heap, 3)

smallest = heap[0]             # 查看最小值但不弹出，O(1)
x = heapq.heappop(heap)        # 弹出最小值，O(log n)，x = 1

nums = [5, 1, 3, 2]
heapq.heapify(nums)            # 把已有 list 原地变成堆，O(n)

if heap:                       # 判断堆是否为空
    ...
```

最小堆：每次弹出的都是当前最小的元素，插入和弹出都是 O(log 大小)

题目中提到了每一个链表都是升序的，所以链表的头一定是最小值，那么我们在push 进最小堆的时候，我们需要用元组机（node.val, index, node) 因为node无法直接直接比较，我们要用node value作为比较的第一因素，在同值的情况下，考虑index,即数组的顺序。每次弹出一个节点后需要将其后续的结点（不为None的情况下），加入堆中。
